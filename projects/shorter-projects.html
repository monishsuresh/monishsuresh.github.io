Dipole antenna simulation with MEEP

Commercial electromagnetic solvers like CST Studio are powerful but expensive. This project tested whether the open-source FDTD package MEEP could reproduce CST results for a reference antenna, a cylindrical dipole.

  • Modelled a cylindrical dipole antenna in MEEP using Python
  • Computed the S-parameters (reflection behaviour over frequency)
  • Computed the far-field radiation pattern
  • Compared my results with reference results a colleague had produced in CST Studio, to validate the MEEP workflow
