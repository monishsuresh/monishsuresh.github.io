Overview

I worked on the embedded firmware of STM32-based devices. Some of the tasks I completed include the following:

  • Configured timers and interrupts to set GPIO pins to predefined values in the absence of UART communication over a set time period
  • Expanded a Modbus command set with new features
  • Added firmware update options to the device
  • Found and fixed bugs in the existing firmware
